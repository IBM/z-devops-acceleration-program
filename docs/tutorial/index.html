IBM Z Systems software trials (IBM Z Trial)​

If you are new to DevOps for z/OS® applications, you might want to explore the workflow and tooling without having to first install and configure an entire technology stack on your own environment. IBM Z® Systems software trials (also known as IBM Z Trial) allows you to try out a variety of IBM Z software experiences in a provisioned environment for free, meaning you can get right to learning how to use these tools/technologies. The following IBM Z Trial experiences are particularly relevant to DevOps and CI/CD pipelines for z/OS applications:

  • IBM® Developer for z/OS on VS Code: Get hands-on with the end-to-end development workflow and practices for developing and maintaining z/OS applications in a modern DevOps environment.

    • Products showcased in this IBM Z Trial include IBM Developer for z/OS on VS Code, IBM Z Open Debug, IBM Dependency Based Build (DBB), and IBM Wazi Deploy. GitLab and Artifactory are included as example CI/CD integrations.
    • Great for z/OS application developers and anyone interested in experiencing the benefits of IBM Z DevOps in the z/OS application development lifecycle.

  • IBM Developer for z/OS® Enterprise Edition (IDzEE) Build and Deploy: This hands-on lab experience contains a set of scenarios with step-by-step instructions to guide you through different workflows to set up, simulate, and analyze builds and deployments of a sample z/OS application using IBM Z DevOps tools.

    • Products covered in this IBM Z Trial experience include IBM DBB (zBuilder framework) and IBM Wazi Deploy, with Artifactory integrated as an example artifact repository. The DBB-Git Migration Modeler capabilities are also explored using GitLab as an example Git provider.
    • Great for z/OS build engineers, DevOps engineers, release engineers, and anyone interested in understanding how to configure IBM Z DevOps tools to onboard and prepare a z/OS application to use a Git-based CI/CD pipeline.

  • IBM Application Delivery Foundation for z/OS®: Explore the range of features in the IBM Application Delivery Foundation for z/OS (ADFz) suite of integrated tooling that can help you analyze, understand, debug, and modify your COBOL programs.

    • Further reading: ADFz Resources contains links to standalone enablement resources for ADFz, IDz, and IBM Z DevOps including videos, blog links, new release announcements, PDFs, and other deep-dive learning content.

For a deeper dive on specific IBM tools and technology stacks, check out our Courses page.
