Work effectively to deliver value with the new tools and practices

The concepts and tools available to support enterprise DevOps are extremely flexible, so it is important to know which techniques and working practices make the most sense for IBM Z® and how high-performing teams get the most out of their DevOps solution.

This part of the guide provides practical insights for many roles across the development lifecycle to use the tools effectively.

Branching with Git version control is so fundamental and powerful that nearly every part of the lifecycle can benefit from it - but there are many patterns from which teams can choose. We explain factors to consider when selecting a Git branching model in Introduction to working practices for teams using Git, and outline typical role-based usage flows with Git and other DevOps tools in the CI/CD pipeline in Role-based usage.

Our recommended branching model for mainframe development serves many scenarios for IBM Z development teams, but is also flexible to accommodate sensible variations. You can see the Git branching model in action video series for a narrated demonstration of our recommended Git branching model.

Another important capability supported by the tools is Audit and Compliance.
